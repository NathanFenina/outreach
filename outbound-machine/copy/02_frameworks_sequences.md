# 02 — Frameworks & séquences prêtes à tester

> Frameworks (pas templates figés). On A/B teste. Variables entre {crochets}.
> Cible pilote proposée : **SaaS/IT · CEO-CMO** (data la plus propre) puis E-commerce, puis BTP/local.

## Banque d'objets (camouflage, minuscules)

- `visibilité ia`
- `carto {secteur}`
- `prompts {marque}`
- `question {domaine}`
- `{concurrent} vs {marque}`
- `page manquante`
- `15 prompts`

## Framework A — "X-Ray GEO" (le plus fort pour Décupler)

Angle : tu es invisible dans les réponses IA de ton marché, ton concurrent y est.

```
Objet : visibilité ia

hello {prénom}, j'ai testé comment ChatGPT et Perplexity répondent quand on cherche {catégorie} —
{concurrent} ressort, {entreprise} n'apparaît sur aucun des prompts que j'ai lancés.

j'ai listé les 15 prompts exacts où vous êtes absents + ce qui fait que {concurrent} est cité à votre place.

(on a fait ça pour Decathlon entre autres)

seriez-vous contre que je vous partage la liste ?

Nathan — Décupler
```
~70 mots. Livrable après "oui" = la liste des 15 prompts + comment y apparaître (Niveau 1/2).

## Framework B — "Page qui capte déjà la demande"

Angle : une requête commerciale que tu ne couvres pas, un concurrent la prend.

```
Objet : page manquante

hello {prénom}, en regardant {site} j'ai vu une intention commerciale autour de « {requête} »
que {concurrent1} et {concurrent2} captent avec une page dédiée — vous, pas encore.

j'ai préparé la mini-carto : la requête, l'angle de page et le potentiel estimé.

je vous l'envoie ?

Nathan — Décupler
```
~60 mots. CTA "je vous l'envoie ?" (friction quasi nulle).

## Framework C — "Échantillon offert" (adapté du mail masterclass Elena/UltB)

Angle : offre un morceau tangible et gratuit, risk-reversal.

```
Objet : carto {secteur}

hello {prénom}, je bosse avec des boîtes {secteur} qui veulent plus de demandes entrantes via le search.
j'ai noté que vous aviez bossé avec {preuve/référence}.

je vous prépare déjà une cartographie des 3 opportunités organiques prioritaires pour {entreprise} — offert, pour vous montrer le niveau.

si l'approche vous parle, on vous montre comment on les transforme en leads. sinon vous gardez tout, sans engagement.

seriez-vous contre un échange de 10 min pour caler ce que vous cherchez ?

Nathan — Décupler

PS : on a gagné 30h/mois sur notre propre SEO en automatisant tout ça.
PPS : pas intéressé ? répondez « stop » et je vous laisse tranquille.
```
~95 mots.

## Framework D — "Loom / vidéo" (Niveau 2-3, comptes à valeur)

CTA = permission d'envoyer une vidéo, pas un RDV.

```
Objet : {marque}

hello {prénom}, j'ai regardé comment {entreprise} apparaît (ou pas) sur les moteurs IA de votre marché.
il y a 2-3 leviers simples pour devenir la source citée à la place de {concurrent}.

je vous fais une vidéo de 3 min qui montre exactement la faille et comment la corriger ?

Nathan — Décupler
```

## Séquence type (Lemlist) — 3 à 4 mails

- **J0 — Mail 1** : Framework A ou C (l'accroche + l'offre d'actif). CTA orienté "non".
- **J+3 — Mail 2 (relance sans pitch)** :
  ```
  Objet : (Re: {objet mail 1})
  hello {prénom}, je voulais juste m'assurer que vous aviez vu — le point qui m'a sauté aux yeux
  c'est {fait précis / 1 prompt concret}. je vous envoie l'analyse ?
  ```
- **J+7 — Mail 3 (offre d'actif "clôture")** :
  ```
  Objet : je vous laisse la carto ?
  hello {prénom}, je clôture le sujet. j'ai déjà préparé la 1ʳᵉ version pour {entreprise}
  (requêtes prioritaires + où vous gagnez en visibilité IA). si c'est pas le moment, aucun souci.
  si vous la voulez, répondez juste « carto ».
  ```
- **J+12 — Mail 4 (breakup, optionnel)** : une ligne, porte de sortie.

## Réponse quand ils disent oui (règle : vendre la rustine, pas le garage)

Ne PAS pitcher toute l'infra. On livre l'actif promis + 1 seule next step :
```
super — voici {la liste / la carto}. {2-3 lignes de valeur réelle}.
le point le plus rentable c'est {X}. je vous montre comment on le met en place en 10 min ?
```

## Variantes par segment (angle = le pain du segment)

- **SaaS/IT** : pages comparaison/alternatives, intégrations, requêtes d'évaluation avant démo, visibilité IA. Persona : CMO / Head of Growth / CEO.
- **E-commerce** : catégories transactionnelles manquantes, guides d'achat, visibilité IA/Shopping, pages catégorie qui rankent mais ne vendent pas. Persona : CEO / CMO / Head of E-com.
- **BTP / Artisans / Clim / Élec (local)** : zones géographiques non couvertes, fiche Google Business Profile, avis, pages "urgence/service+ville". CTA plus simple, orienté **appels/devis**. → souvent meilleur en **cold call** (cohorte call).
- **Agence-Ads / Consulting** : white-label, delivery qui craque, capacité. Angle capacité/exécution.

## Variantes géographiques (voir 00_ideas_capture.md §D)

- **France** : FR, tutoiement léger/vouvoiement selon persona.
- **Afrique subsaharienne** : FR (+ EN selon pays), maturité GEO plus faible → angle "prenez l'avance sur la visibilité IA".
- **Middle East** : EN (+ AR à évaluer), fuseaux horaires Golfe, angle premium/marque.
- Prévoir : domaines/inboxes dédiés par géo si volume, horaires d'envoi par fuseau.

## À tester en premier (proposition)

1 ICP : **SaaS/IT · CEO-CMO · FR**. 2 angles en A/B : **Framework A (X-Ray GEO)** vs **Framework C (échantillon carto)**.
Objectif : trouver l'angle qui sort le meilleur taux de **réponse positive** avant de scaler.
