# 50 · Réponses types vague 1 (méthode Igor) · 11/11

Règles : répondre vite (même jour), court, vouvoiement en FR, une seule question. Intéressé → vidéo 3 min puis Calendly ; relance LinkedIn si pas de réservation après 2 jours ouvrés.
Réponse au mail 4 « 1-2-3 » : traiter le chiffre (1 = déjà premiers, 2 = pas prioritaire, 3 = humour → relancer en douceur).
