## TL;DR de la doctrine
1. Le mail **qualifie**, il ne vend pas. But = permission de livrer un **actif tangible gratuit**.
2. **Reverse lead magnet + X-Ray** : montrer UNE faille vérifiable, réparer APRÈS le "oui".
3. Objet camouflage (1-2 mots minuscules) · 80-120 mots · CTA orienté "non".
4. **Relevance > personnalisation** (anti AI-slop). 1 ICP + 1 pain + 1 offre par campagne.
5. Infra horizontale, volume medium, on scale **après** avoir validé un angle.
6. Analyse en 3 niveaux (léger/enrichi/ABM) pour ne pas exploser les coûts IA.
